<h4>Autonomous Root Tip Inoculation</h4>
<sub><i>Individual project · Built for <a href="https://www.npec.nl/">NPEC</a> · Nov 2025 – Jan 2026</i></sub>

<p>Finds <i>Arabidopsis</i> root tips on a petri dish and drives a simulated Opentrons OT-2 pipette to inoculate each one. Segmentation uses a patch-based U-Net with test-time augmentation; tips are located by tracing each primary root through its skeleton graph.</p>

<p>For the pipette I trained a PPO agent and tuned a PID controller. PID converged cleanly where the agent oscillated around target, so it went into the final system. <b>96% success across 10 simulated plates.</b></p>
